# 위키 글 고치는 법 (옵시디언)

이 폴더(`content`)가 사이트 **개념 위키의 원본**입니다. 여기 노트를 고치면 사이트 [IVDR 여정 위키](https://mungbws1031.github.io/ivdr-wiki/wiki)의 글이 바뀝니다.

> [!WARNING]
> 이 저장소와 사이트는 **인터넷에 공개**됩니다. 회사 내부 문서(사내 절차서·양식·제품 수치)는 이 폴더에 넣지 마세요. 회사 문서는 다른 옵시디언 볼트에 따로 둡니다.

## 처음 한 번

1. 옵시디언 → **보관함 열기 → 폴더를 보관함으로 열기** → 이 저장소의 `content` 폴더를 고릅니다.
2. 왼쪽에 `wiki` 폴더(개념 노트 28개), `_templates`(새 노트 양식), `위키 개념 목록`(표 보기)이 보이면 성공입니다.

## 글 고치기

- `wiki` 폴더에서 노트를 열어 본문을 고칩니다. 문단은 **빈 줄 한 줄**로 나눕니다.
- 다른 개념으로 연결: `[[annex-viii|분류]]` — 앞은 **파일 이름**, 뒤는 **화면에 보일 글자**입니다. `[[`를 치면 옵시디언이 목록을 띄워 줍니다.
- 굵게: `**굵게**`. 제목(#)·목록(-)·표·이미지는 사이트에서 서식 없이 글자로만 보입니다.

## 새 개념 만들기

1. `wiki` 폴더에 새 노트를 만들고, 파일 이름을 **영문 소문자·숫자·하이픈**으로 정합니다. 예: `ifu-languages` (이 이름이 사이트 주소가 됩니다)
2. 명령 팔레트(Ctrl+P) → **템플릿: 템플릿 삽입** → `위키 개념`
3. 맨 위 속성 칸을 채웁니다.

| 속성 | 뜻 | 예 |
|---|---|---|
| term | 제목 | Annex VIII — 분류 규칙 |
| aliases | 다른 이름 (검색·링크에 쓰임) | Annex VIII, 분류 규칙 |
| category | 분류: annex(부속서) · standard(국제 표준) · concept(핵심 개념) · actor(행위자·기관) · deliverable(산출물 문서) | annex |
| summary | 한 줄 정의 (목록·칩에 보임) | Rule 1~7로 A~D 등급을 정하는 규칙 |
| refs | 규정 근거 | IVDR Annex VIII, Art.47 |
| stations | 연결할 정거장 번호 | 2 |
| related | 함께 볼 개념 (링크로 적으면 그래프에 연결이 보임) | [[notified-body]] |
| order | 목록 순서 (작을수록 앞) | 285 |
| status | `draft`(초안, 사이트에 안 나감) / `published`(공개) | draft |

다 쓰면 `status`를 `published`로 바꿉니다.

## 사이트에 올리기

고친 노트를 GitHub `main`에 올리면(commit·push) 몇 분 뒤 사이트에 반영됩니다.
- 옵시디언 커뮤니티 플러그인 **Git**을 쓰면 옵시디언 안에서 바로 올릴 수 있습니다.
- 또는 **GitHub Desktop**에서 "Commit → Push"를 누릅니다.

## 실수하면?

올릴 때 자동 검사가 돌아갑니다. **없는 개념으로 가는 링크, 빈 제목·요약, 잘못된 파일 이름**이 있으면 반영이 멈추고 **사이트는 이전 상태 그대로** 남습니다. GitHub의 Actions 탭에서 어느 노트의 어디가 문제인지 한국어로 볼 수 있습니다. 초안(`draft`) 노트는 덜 써도 반영을 막지 않습니다.

# 4F 성능평가 실험실 — 담당 문서 상세

앱의 문서 템플릿(`src/data/documents.ts`)과 문서 트리(`src/data/docTree.ts`)에서 자동으로 만든 목록이다. 섹션 순서를 바꾸지 않는다.

## 성능평가 (Annex XIII)
근거: Annex XIII, Art.56

### 성능평가 계획 (PEP) (`performance-eval-plan`)

- 필요 여부: 필수
- 근거 조항: Annex XIII, Art.56
- 앱에서 열기: `/doc/performance-eval-plan` (전용 상세 템플릿)
- 왜 쓰는가: IVDR Annex XIII은 '증거 기반' 성능평가를 요구한다. PEP는 PER보다 먼저 작성해 NB·시험기관과 설계를 합의하는 청사진이다. MDCG 2025-5는 성능연구 유형과 절차를 명확히 하고 있다.
- 작성 전 준비물: 의도된 목적 정의서 (intended-purpose); 분류 근거서 — Class 확정 필요; 분석물질-임상상태 연관 주요 문헌 3편 이상; 경쟁 제품 성능 사양 벤치마크
- 알아야 할 것: IVDR Annex XIII — 과학적 타당성·분석적 성능·임상적 성능 3단 개념; MDCG 2025-5 — 성능 연구 유형·절차 명확화 지침; LoD(검출 한계)·LoQ(정량 한계)·정밀도(반복성·재현성) 차이; 민감도·특이도·PPV·NPV와 유병률의 관계; 참고 측정법(Reference Standard) 비교 연구 설계; Class C·D는 임상 성능 연구가 필요 (Annex XIII Part B)
- 섹션 순서:
  1. 1. 과학적 타당성 (Scientific Validity)
  2. 2. 분석적 성능 연구 설계
  3. 3. 임상적 성능 연구 설계
  4. 4. 연구 일정 및 책임

### 과학적 타당성 보고서 (`scientific-validity`)

- 필요 여부: 필수
- 근거 조항: Annex XIII 1.2
- 앱에서 열기: `/doc/scientific-validity` (기본 템플릿)
- 왜 쓰는가: 측정 대상이 정말 그 임상 상태와 연관되는지가 모든 성능의 전제다. 이 전제가 무너지면 분석·임상 성능 데이터도 무의미해진다.
- 작성 전 준비물: 문헌 검색 전략·결과; 분석물질-임상상태 연관 근거
- 알아야 할 것: 분석물질-임상상태 연관의 근거 수준; 문헌 검색·평가 방법; 기존 합의·가이드라인 존재 여부
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

### 분석적 성능 보고서 (`analytical-performance`)

- 필요 여부: 필수
- 근거 조항: Annex XIII 1.2.2
- 앱에서 열기: `/doc/analytical-performance` (기본 템플릿)
- 왜 쓰는가: 기기가 측정값을 정확·정밀하게 내는지 입증해야 결과를 신뢰할 수 있다. 검사 결과의 기술적 신뢰성의 근거다.
- 작성 전 준비물: 정밀도·정확도·검출한계·교차반응 시험 데이터; 검체 패널 정보·출처; 시험 셋업·결과 이미지(해당 시)
- 알아야 할 것: 정밀도·정확도·LoD·LoQ 등 지표의 정의; 교차반응·간섭 평가 방법; 참조 물질·방법
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 실험 설계
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인
  5. 5. 판정 기준
  6. 6. 결과
  7. 7. 결론

### 임상적 성능 보고서 (`clinical-performance`)

- 필요 여부: 필수
- 근거 조항: Annex XIII 1.2.3
- 앱에서 열기: `/doc/clinical-performance` (기본 템플릿)
- 왜 쓰는가: 정확한 측정값이 실제 임상 판단에서 유효한지(민감도·특이도)를 보여야 한다. 환자에게 실질적 가치가 있음을 입증한다.
- 작성 전 준비물: 임상 성능 연구 데이터(민감도·특이도); 연구 계획서·윤리 승인; 검체 출처·수·대상군
- 알아야 할 것: 민감도·특이도·예측도의 의미; 적절한 대상군·검체 수; 연구 설계(전향/후향)와 윤리 요건
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 연구 설계
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인
  5. 5. 표본수 근거
  6. 6. 판정 기준
  7. 7. 결과 · 결론

### 성능평가 보고서 (PER) (`performance-eval-report`)

- 필요 여부: 필수 — PEP→데이터→PER로 종결.
- 근거 조항: Annex XIII, Art.56
- 앱에서 열기: `/doc/performance-eval-report` (전용 상세 템플릿)
- 왜 쓰는가: 흩어진 성능 증거를 하나의 결론으로 종합해 '이 기기는 의도된 목적에 충분하다'를 선언한다. NB 심사의 핵심 산출물이다.
- 작성 전 준비물: PEP·과학적타당성·분석·임상 보고서; 종합 성능 결론·잔여 위험
- 알아야 할 것: PEP 대비 결과의 충족 여부 판단; 잔여 위험·한계의 기술 방법; 결론 도출 논리
- 섹션 순서:
  1. 1. 과학적 타당성 결론
  2. 2. 분석적 성능 결론
  3. 3. 임상적 성능 결론
  4. 4. 종합 결론 및 잔여 성능 불확도

### 계측학적 추적성 (지정값) (`metrological-traceability`)

- 필요 여부: 해당 시 — 정량 검사 — 교정물질·관리물질 지정값에 적용.
- 근거 조항: Annex I 9.4, ISO 17511
- 앱에서 열기: `/doc/metrological-traceability` (기본 템플릿)
- 왜 쓰는가: 정량 IVD 결과가 신뢰되려면 지정값이 상위 참조까지 추적 가능해야 한다. 검사실 간·시점 간 결과 일관성을 보장한다.
- 작성 전 준비물: 교정 계층·참조 물질; 값 지정(value assignment) 데이터; 측정 불확도 추정
- 알아야 할 것: 지정값 추적 계층(ISO 17511); 참조 물질·방법의 등급; 측정 불확도 추정 방법
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

### 임상·성능 연구 계획서/신청 (CPSP) (`clinical-performance-study-plan`)

- 필요 여부: 조건부 — 중재적 임상성능 연구 시 — 윤리 승인·EUDAMED 신청.
- 근거 조항: Annex XIII Part A, Annex XIV, Art.58
- 앱에서 열기: `/doc/clinical-performance-study-plan` (기본 템플릿)
- 왜 쓰는가: 사람 대상으로 임상 증거를 새로 만들 때는 피험자 안전과 데이터 신뢰성을 위해 사전 계획·윤리 승인·당국 신청이 필수다. 무계획 연구의 데이터는 인정되지 않는다.
- 작성 전 준비물: 연구 가설·의도된 목적; 연구 설계·검체·통계; 윤리위원회·당국 신청 양식
- 알아야 할 것: 중재적 vs 비중재적 성능연구 구분; Annex XIV 신청·승인 절차; 윤리·동의·피험자 안전 요건
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

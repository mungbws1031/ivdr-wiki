# 6F RA 규제 — 담당 문서 상세

앱의 문서 템플릿(`src/data/documents.ts`)과 문서 트리(`src/data/docTree.ts`)에서 자동으로 만든 목록이다. 섹션 순서를 바꾸지 않는다.

## 범위·분류
근거: Art.2, Annex VIII

### 의도된 목적 정의서 (`intended-purpose`)

- 필요 여부: 필수
- 근거 조항: Annex II 1.1, Art.2
- 앱에서 열기: `/doc/intended-purpose` (전용 상세 템플릿)
- 왜 쓰는가: 의도된 목적은 규제 적용 범위·분류·성능 요구의 '원점'이다. 여기서 한 단어가 틀어지면 이후 모든 증거가 잘못된 기준으로 만들어지므로, 가장 먼저 정확히 못 박아 재작업과 심사 거절을 막는다.
- 작성 전 준비물: 측정 대상·검체·사용자·환경·임상 결정 정보; 제품 컨셉·마케팅 자료; 경쟁·유사 제품 라벨/IFU 예시
- 알아야 할 것: 내 제품이 검출/측정하는 정확한 대상과 그 임상적 의미; 타깃 사용자·사용 환경(전문가/자가검사, 실험실/가정); 결과가 어떤 임상 결정을 보조하는지
- 섹션 순서:
  1. 1. 제품 식별
  2. 2. 의도된 목적 (5요소)
  3. 3. IVD 해당성 판단
  4. 4. 미사용 목적 (Out of scope)

### 제품 적격성(IVD 해당성) 판단서 (`qualification-statement`)

- 필요 여부: 필수 — IVDR 적용 대상인지 근거와 함께 판단.
- 근거 조항: Art.2
- 앱에서 열기: `/doc/qualification-statement` (기본 템플릿)
- 왜 쓰는가: 내 제품이 애초에 IVDR 대상인지부터 확정해야 불필요하거나 누락된 규제 부담을 피한다. 적용 여부를 근거와 함께 남겨 당국·NB 질의에 즉시 답할 수 있게 한다.
- 작성 전 준비물: 의도된 목적 정의서(초안); 제품 작동 원리·검출 메커니즘 설명; IVDR Art.2 정의 대조표
- 알아야 할 것: IVDR Art.2의 IVD 정의 요건; 내 제품이 정의의 어느 요소에 해당/비해당하는지; 경계 사례(연구용·일반 제품)와의 구분 기준
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

### 분류 근거서 (`classification-rationale`)

- 필요 여부: 필수
- 근거 조항: Annex VIII, Art.47
- 앱에서 열기: `/doc/classification-rationale` (전용 상세 템플릿)
- 왜 쓰는가: 클래스는 NB 개입·평가 경로·전환 기한을 통째로 결정한다. 분류와 그 근거를 남기는 것은 '왜 이 경로인가'를 입증해 심사에서 가장 먼저 신뢰를 얻기 위함이다.
- 작성 전 준비물: 의도된 목적 정의서; 검출 대상의 임상적 위험(감염성·생명위협 여부); Annex VIII Rule 1~7 체크 시트
- 알아야 할 것: Annex VIII Rule 1~7의 적용 순서와 우선순위; 자가검사/근접검사가 분류에 미치는 영향(Rule 4); 둘 이상 해당 시 최고 등급 채택 원칙
- 섹션 순서:
  1. 1. 의도된 목적 요약
  2. 2. Rule 적용 내역
  3. 3. 최종 분류 및 근거
  4. 4. 경로 영향

### 적합성 평가 경로 계획 + 산출물 체크리스트 (`conformity-route-plan`)

- 필요 여부: 필수
- 근거 조항: Art.48, Annex IX~XI
- 앱에서 열기: `/doc/conformity-route-plan` (전용 상세 템플릿)
- 왜 쓰는가: 경로를 먼저 확정해야 어떤 증거를 만들지가 정해진다. 계획 없이 착수하면 경로가 바뀔 때 증거 전체를 다시 만들게 되므로, 재작업과 일정 리스크를 줄인다.
- 작성 전 준비물: 분류 근거서(클래스 확정); 클래스별 Annex IX~XI 경로 비교표
- 알아야 할 것: 클래스별 가능한 Annex 경로(IX/X/XI)의 차이; 각 경로에서 NB가 심사하는 범위; 경로별로 필요한 산출물
- 섹션 순서:
  1. 1. 클래스 및 경로 선택
  2. 2. 산출물 체크리스트
  3. 3. NB 관여 범위

## 적합성·인증
근거: Art.17~18, Art.38~46

### NB 신청 패키지·선정 체크리스트 (`nb-application`)

- 필요 여부: 조건부 — Class A 비멸균은 NB 생략.
- 근거 조항: Art.38~46
- 앱에서 열기: `/doc/nb-application` (전용 상세 템플릿)
- 왜 쓰는가: Class A 비멸균 외에는 제3자 검증 없이 시장에 나갈 수 없다. 객관적 인증으로 적합성에 대한 신뢰를 확보한다. NB 슬롯 지연은 곧 시장 차단이므로 조기 준비가 핵심이다.
- 작성 전 준비물: QMS·기술문서·PER·위험파일(준비 완료); NANDO scope 조사 결과; NB 견적·서면 계약
- 알아야 할 것: 내 클래스의 NB 개입 여부; NB scope(NANDO)와 매칭; 심사 단계·소요 기간
- 섹션 순서:
  1. 1. NB 후보 선정
  2. 2. 계약·일정
  3. 3. 신청 패키지

### 적합성 선언서 (DoC) (`declaration-of-conformity`)

- 필요 여부: 필수
- 근거 조항: Annex IV, Art.17
- 앱에서 열기: `/doc/declaration-of-conformity` (전용 상세 템플릿)
- 왜 쓰는가: 제조자가 법적 책임을 지고 'IVDR을 충족한다'고 선언하는 문서다. CE 부착의 법적 근거이자 책임 소재의 명문화다.
- 작성 전 준비물: 기술문서 일체·NB 인증서(해당 시); 제조자·Basic UDI-DI·분류·적용 표준
- 알아야 할 것: IVDR Annex IV — DoC 필수 기재 항목 (제조자·기기식별·분류·규정·표준·NB·서명); Basic UDI-DI는 기기 등록 전에 발행기관(GS1 등)에서 발급받아야 함; EU 대리인은 비EU 제조자에게만 해당; Class A(자가측정 제외)만 자기 선언 가능 — B/C/D는 NB 번호 필수; EUDAMED에 DoC 사본 업로드 의무 (2026.01부터 의무화 — EU 2024/1860)
- 섹션 순서:
  1. 1. 제조자·대리인
  2. 2. 기기 식별
  3. 3. 적합성 선언 내용
  4. 4. 서명

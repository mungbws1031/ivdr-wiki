## C — 공통 (다섯 위원 모두)

| ID | 항목 | 확인 방법 | 통과 기준 | 심각도 |
|---|---|---|---|---|
| C-01 | 수치를 지어내지 않는다 | 위험관리 계획 2절, 성능 문서, 510(k) 초안 | 위험 P·S, 성능 값, 반응 시간, 검체 부피, 비교 기기 번호가 모두 빈칸(`[__]`·`[실험 후 입력]`) | 치명 |
| C-02 | 조항·규정 번호를 지어내지 않는다 | 국가별 화면·문서의 인용 | 확인한 번호만 쓰고, 나머지는 "원문 확인 필요"·"제품 코드 확인" | 치명 |
| C-03 | 등급은 추천이고 사람이 확정한다 | `/auto/docs` 확정 버튼, `/auto/kr` 확인 등급, `/auto/us` 제품 코드 | 확정·확인 값이 추천보다 우선하고, 다르면 경고 | 치명 |
| C-04 | 가정·추정 표시 | 컨셉 한 줄만 넣고 문서 열기 | 비어 있는 값을 채운 곳에 "(가정)"·"(추정)"이 붙고 배너가 보인다 | 주요 |
| C-05 | 사람이 쓴 초안 보호 | 섹션을 직접 쓴 뒤 스펙 변경 | 직접 쓴 섹션은 바뀌지 않고 "재검토 필요"만 표시 | 치명 |
| C-06 | 규칙 검토 상태 표시 | 각 국가 화면 아래 | 검토자·날짜, 또는 "검토 전 참고용" 표시 | 주요 |
| C-07 | 근거 원장 | 결과 한눈에, 문서 화면 | 입력·규칙·가정·추정·누락 수와 확정 % | 경미 |
| C-08 | 변경 영향 | 문서를 연 뒤 스펙을 바꾸고 다시 열기 | 바뀐 값과 영향받는 섹션 표시 | 주요 |
| C-09 | 저장 위치 안내·백업 | 스펙 화면 | "브라우저에만 저장" 안내, 내보내기·가져오기 동작 | 주요 |
| C-10 | 내보내기에 초안 표시 | Word·파이프라인 zip | "검토 전 초안" 표시, 빈칸 유지 | 주요 |

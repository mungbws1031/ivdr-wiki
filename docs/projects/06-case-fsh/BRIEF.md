# 06 사례 적용: 갱년기 FSH

- 묶음: 사례·사업 · 시작 조건: **바로 가능**

## 목표
'내 소변으로 갱년기 관리 시작' 컨셉을 실제로 끝까지 밀어 보며 앱의 빈 곳을 찾는다.

## 왜
가상 예시(LH)만으로는 못 찾는 문제가 있다(혈당·FSH 판정 오류가 실제 컨셉에서 나왔다).

## 범위
넣을 것
- 컨셉 → 스펙 완성, 시장 리포트 값을 시장성 화면에 입력
- IFU·라벨 문구: '진단 아님, 호르몬 변화 모니터링'
- 식약처 FSH 허용 품목·등급 확인 목록, IVDR B/C 판단 메모
- 발견한 앱 문제를 이슈 목록으로

뺄 것
- 실제 시험 수치 생성

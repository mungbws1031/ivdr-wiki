# 06 사례 적용: 갱년기 FSH — IFU·라벨 문구 초안

> `draftTokens()` 실제 실행 결과를 바탕으로 쓴 초안이다. 시간·부피·판정 기준 등 수치는 분석·임상 성능 시험 결과로 확정하기 전까지 `[__]`로 비워 둔다. 지어낸 수치 없음.

## 0. 안전 문구 (맨 앞에 반드시 넣을 것 — BRIEF 요구)

> **진단 아님, 호르몬 변화 모니터링.**
> 이 검사는 갱년기(폐경 이행기)를 진단하지 않습니다. 소변 속 FSH(난포자극호르몬) 수치 변화를 관찰해 호르몬 변화를 모니터링하는 보조 도구입니다. 결과만으로 치료를 시작·중단하지 말고 의사와 상담하십시오.

### 앱이 자동으로 채운 문구와 다르다 — 사람이 고를 것

`src/lib/concept.ts`의 `DECISION.other`가 자동으로 채운 `intendedPurpose.clinicalDecision` 값은 다음과 같다:

> "폐경 이행기(갱년기) 여부 확인 보조"

이 문구는 BRIEF가 요구한 안전 문구("진단 아님, 호르몬 변화 모니터링")와 뉘앙스가 다르다 — "여부 확인"은 양성/음성 판정처럼 들릴 수 있고, "진단 아님"이라는 부정 표현이 빠져 있다. 아래 두 문구 중 하나를 고르거나 다듬어야 한다(이슈 F-14, `issues.md` 참고):

| 출처 | 문구 |
|---|---|
| 앱 자동 채움 (concept.ts) | 폐경 이행기(갱년기) 여부 확인 보조 |
| BRIEF 요구 (사람이 정한 안전 문구) | 진단 아님, 호르몬 변화 모니터링 |

이 문서의 나머지 초안은 BRIEF 요구 문구를 기준으로 작성한다.

## 1. 라벨 — 심볼 (`labelSymbols()` 실행 결과)

| 심볼 (ISO 15223-1 — 기호 번호·도안은 원문 확인 필요) | 쓰는 이유 |
|---|---|
| 체외진단 의료기기 (IVD) | 체외진단용임을 표시 |
| 제조자 | 제조자 이름·주소와 함께 ([회사명 미입력]) |
| 배치 코드 (LOT) | 로트 번호 |
| 카탈로그 번호 (REF) | 제품 번호 |
| 사용 기한 | 유효기간 날짜 |
| 사용설명서 참조 | IFU를 읽으라는 표시 |
| 재사용 금지 | 1회용 스트립·카세트 |
| 검사 수 표시 (n개 검사용) | 키트당 검사 수 |
| 자가검사용 표시 | 일반인 자가검사 기기 |
| CE 마크 | NB 식별번호 `[____]` 함께 표시 |
| UDI | UDI 캐리어 (GS1 DataMatrix 등) |

보관 온도 심볼은 `storage.tempMinC/tempMaxC`를 아직 입력하지 않아 이 실행에서는 빠졌다 — 실제 제품이면 추가해야 한다.

## 2. 라벨 경고문 (`labelWarnings()` 실행 결과)

- 체외진단용으로만 사용하십시오.
- 유효기간이 지난 제품은 사용하지 마십시오. 파우치가 손상되었으면 사용하지 마십시오.
- 1회용입니다. 다시 사용하지 마십시오.
- 사용한 스트립·검체 용기는 감염 위험이 있는 폐기물로 보고 지역 규정에 따라 버리십시오.
- 어린이의 손이 닿지 않는 곳에 보관하십시오.
- 검사 결과만으로 의학적 결정을 내리지 말고, 결과가 예상과 다르면 의사와 상담하십시오.

(제품 정보로 쓴 초안 — 위험관리 결과와 맞춰 검토 필요)

## 3. IFU — 작동 원리 (일반인용, `principleLay()` 실행 결과)

1. 소변을 검사 막대에 묻히면 검체가 막대를 따라 스며듭니다.
2. 소변 속에 난포자극호르몬(FSH)이 기준보다 많으면 검사창에 선이 하나 더(T선) 나타납니다.
3. C선은 검사가 제대로 되었는지 알려 주는 선으로, 결과와 관계없이 항상 나타나야 합니다.
4. 검사창에 나타난 선을 눈으로 확인합니다.

> 원문 그대로는 "난포자극호르몬(FSH) — 확인 필요"로 나왔다("확인 필요" 꼬리말은 분석물 명칭이 아직 사람이 확정하지 않았음을 뜻한다). 사람이 확정하면 꼬리말은 사라진다.

## 4. IFU — 사용 절차 (`ifuSteps()` 실행 결과)

1. 준비: 검사 키트와 검체를 실온(`[__–__℃]`)에 `[__분]` 둡니다. 파우치를 열어 구성품을 확인합니다.
2. 검체 채취·적용 (소변): 깨끗한 용기에 소변을 받거나, 스트립 끝을 소변 줄기에 `[__초]` 대거나 용기의 소변에 `[__초]` 담급니다. 하루 중 검사 시간은 `[권장 시간 — 확인 필요]`.
3. 평평한 곳에 두고 `[__분]` 기다립니다. `[__분]`이 지난 뒤의 결과는 읽지 않습니다.
4. 결과 판독: 아래 결과 판독 기준에 따라 선을 확인합니다.
5. 사용한 구성품을 경고에 따라 버립니다.

(시간·부피는 분석 성능·사용적합성 시험 결과로 확정)

## 5. IFU — 결과 판독 기준

이 사례는 `result.kind`(정성/정량)를 컨셉 문장에서 뽑지 못해 `ifuReading()`이 `null`을 반환했다 — 사람이 직접 결정해야 한다:
- 정성(양성/음성)으로 할지, 정량(수치)으로 할지에 따라 판독 기준 문구가 달라진다.
- 참고: LH 사례는 "시험선이 대조선과 같거나 더 진하면 LH 급증으로 봅니다"처럼 preset별 전용 문구가 있지만, FSH는 preset이 "other"라 전용 문구가 없다. `[판정 기준 — 확인 필요]`로 남겨 둔다.

## 6. IFU — 사용상의 제한 (`ifuLimitations()` 실행 결과)

- 이 검사 결과만으로 진단하지 마십시오. 증상과 다른 검사 결과를 함께 고려해야 합니다.
- 간섭 물질·교차반응 물질: `[분석 성능 시험 결과 참조]`
- 고농도에서 결과가 낮게 나올 수 있는지(hook 효과): `[분석 성능 시험 결과 참조]`

> FSH는 preset이 "other"라 LH·hCG·glucose처럼 전용 제한 문구(예: "다낭성 난소 증후군은 결과에 영향을 줄 수 있습니다")가 자동으로 붙지 않는다. 사람이 추가해야 한다 — 예: "일부 호르몬 치료제·난소 수술 이력·다른 내분비 질환이 FSH 수치에 영향을 줄 수 있습니다. (검토 필요)"

## 7. IFU — 경고문 (`ifuWarnings()` 실행 결과)

라벨 경고문(2장)과 동일한 목록을 IFU에도 넣는다(`ifuWarnings()`는 `labelWarnings()`와 같은 `warnings()` 함수를 쓰며, 뒤에 붙는 안내 문구만 다르다).

## 8. 결론 — IFU·라벨에 넣을 안전 문구 최종본 (권고)

표지·사용 목적 첫 줄에:

> **진단 아님, 호르몬 변화 모니터링.** 이 제품은 폐경 이행기(갱년기) 여부를 진단하지 않으며, 소변 FSH 수치의 변화 추이를 보여 주는 보조 도구입니다.

앱이 자동으로 채운 "폐경 이행기(갱년기) 여부 확인 보조"라는 문구를 쓸 경우, 최소한 "확인 보조"가 진단이 아니라는 점을 IFU 첫 문장에서 명확히 해야 한다. 어느 쪽을 최종으로 쓸지는 RA 담당자·사람이 확정해야 한다(F-14, `issues.md`).

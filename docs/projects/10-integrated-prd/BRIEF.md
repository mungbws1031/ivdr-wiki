# 10 통합 PRD·사업화

- 묶음: 사례·사업 · 시작 조건: **바로 가능**

## 목표
DesignFlow MD PRD와 ivdr-wiki를 합친 통합 PRD와 PoC 서비스 패키지를 만든다.

## 왜
두 제품은 앞단(규제 전략)과 중간(추적성)으로 보완 관계다. 판매 순서(컨설팅 → 구축 → SaaS)에 맞춘 자료가 필요하다.

## 범위
넣을 것
- 통합 PRD(검토 의견 10개 반영)
- PoC 패키지: 입력(DDI·FMEA·검증) → 출력(매트릭스·빠진 연결·커버리지 보고서)
- KPI 기준값 측정 방법

뺄 것
- 가격 확정

## 관련 파일
- `docs/PRD.md`

## 선행 조건
- 사용자 사업 방향 결정

## 완료 기준
- 통합 PRD 문서, PoC 제안서 초안

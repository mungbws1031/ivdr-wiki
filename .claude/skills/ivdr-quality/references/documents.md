# 2F 품질(QA) — 담당 문서 상세

앱의 문서 템플릿(`src/data/documents.ts`)과 문서 트리(`src/data/docTree.ts`)에서 자동으로 만든 목록이다. 섹션 순서를 바꾸지 않는다.

## 품질경영시스템 (QMS)
근거: Art.10(8), ISO 13485

### QMS↔IVDR 연계 매트릭스 (`qms-ivdr-matrix`)

- 필요 여부: 필수
- 근거 조항: Art.10(8), ISO 13485:2016
- 앱에서 열기: `/doc/qms-ivdr-matrix` (전용 상세 템플릿)
- 왜 쓰는가: 품질은 문서 한 장이 아니라 시스템으로 보장된다. ISO 13485에 IVDR 고유 요구를 연결해 일관된 품질과 규제 준수의 토대를 만든다.
- 작성 전 준비물: ISO 13485 절차서 목록·품질매뉴얼; IVDR 고유 프로세스 매핑표
- 알아야 할 것: ISO 13485와 IVDR 요구의 차이; IVDR 고유 프로세스 목록; 절차서-요구 매핑 방법
- 섹션 순서:
  1. 1. QMS 기준
  2. 2. IVDR 고유 프로세스 연계
  3. 3. Art.10(8) 충족 근거

### 문서·기록 관리 절차(SOP) (`doc-record-control`)

- 필요 여부: 필수
- 근거 조항: ISO 13485 4.2
- 앱에서 열기: `/doc/doc-record-control` (기본 템플릿)
- 왜 쓰는가: 추적성과 버전 관리가 없으면 어떤 증거도 신뢰할 수 없다. 올바른 문서가 올바른 시점에 쓰이도록 보장한다.
- 작성 전 준비물: 기존 문서관리 절차; 문서 분류·보존 기간 정책
- 알아야 할 것: 문서 vs 기록의 구분; 버전·승인·배포 통제 원칙; 보존 기간 요건
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

## 시판 후 (Annex III)
근거: Art.78~81, Annex III

### 시판 후 감시 계획 (PMS Plan) (`pms-plan`)

- 필요 여부: 필수
- 근거 조항: Art.79, Annex III
- 앱에서 열기: `/doc/pms-plan` (전용 상세 템플릿)
- 왜 쓰는가: IVDR 인증은 출시 시점의 결과물이 아니라 지속적 의무다. MDCG 2025-10은 MDR/IVDR 통합 PMS 지침을 제공한다. Class C·D는 매년 PSUR을 제출해야 하며, SSCP도 의무다.
- 작성 전 준비물: 성능평가 보고서 (PER) — 기준점 성능 지표; 위험관리 파일 — 갱신 트리거 조건; 고객 불만·바이질런스 수집 채널 (ERP/CRM)
- 알아야 할 것: IVDR Art.78~81 — PMS·PMPF·PSUR·바이질런스 의무 체계; MDCG 2025-10 — MDR/IVDR 통합 PMS 가이드 (2025.12 시행); PSUR (Periodic Safety Update Report) — Class C·D 연간, 기타 2년; SSCP (Summary of Safety and Clinical Performance) — Class C·D 의무 공개; PMPF (Post-Market Performance Follow-up) — Annex XIII Part B; EUDAMED 사고 보고 의무 (심각한 사고는 15일 내)
- 섹션 순서:
  1. 1. PMS 계획
  2. 2. PMPF 계획
  3. 3. PSUR 일정
  4. 4. 환류 경로

### 정기 안전성 갱신 보고서 (PSUR) (`psur`)

- 필요 여부: 조건부 — Class C·D는 매년 갱신.
- 근거 조항: Art.81
- 앱에서 열기: `/doc/psur` (기본 템플릿)

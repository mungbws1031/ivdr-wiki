# 3F 생산 — 담당 문서 상세

앱의 문서 템플릿(`src/data/documents.ts`)과 문서 트리(`src/data/docTree.ts`)에서 자동으로 만든 목록이다. 섹션 순서를 바꾸지 않는다.

## 생산·공정 (Production)
근거: ISO 13485 7.5

### 공정 밸리데이션 (IQ/OQ/PQ) (`process-validation`)

- 필요 여부: 필수
- 근거 조항: ISO 13485 7.5.6
- 앱에서 열기: `/doc/process-validation` (기본 템플릿)
- 왜 쓰는가: 전수검사로 확인할 수 없는 공정이 일관된 결과를 내는지 입증해 품질의 재현성을 보장한다.
- 작성 전 준비물: 공정 흐름·관리점; IQ·OQ·PQ 데이터; 공정 파라미터·수용 기준
- 알아야 할 것: 밸리데이션 필요 공정 식별; IQ/OQ/PQ의 의미; 재밸리데이션 트리거
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

### 멸균 밸리데이션 (`sterilization-validation`)

- 필요 여부: 해당 시 — 멸균 기기에 한함.
- 근거 조항: ISO 11135, ISO 11137
- 앱에서 열기: `/doc/sterilization-validation` (기본 템플릿)
- 왜 쓰는가: 멸균이 표시된 무균보증수준(SAL)을 실제 달성하는지 입증해 감염 위험을 차단한다.
- 작성 전 준비물: 멸균 밸리데이션 데이터; SAL·잔류물 기준; 포장·무균보증
- 알아야 할 것: 멸균 방식·SAL 개념; 잔류물·생물학적 지표; 재밸리데이션 주기
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

### 기기 마스터 기록 (DMR) (`dmr`)

- 필요 여부: 필수
- 근거 조항: ISO 13485 4.2.3
- 앱에서 열기: `/doc/dmr` (기본 템플릿)
- 왜 쓰는가: 기기를 만드는 데 필요한 모든 사양·절차를 한 세트로 정의해 일관된 생산을 보장한다.
- 작성 전 준비물: 사양·도면·BOM·작업지시; 라벨·검사 기준
- 알아야 할 것: DMR 구성 항목; DHF와의 차이; 버전·변경 통제
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

### 기기 이력 기록 (DHR/배치기록) (`dhr`)

- 필요 여부: 필수
- 근거 조항: ISO 13485 7.5.1
- 앱에서 열기: `/doc/dhr` (기본 템플릿)
- 왜 쓰는가: 각 배치가 DMR대로 만들어졌음을 기록해 추적성과 리콜 대응을 가능케 한다.
- 작성 전 준비물: 생산·검사·릴리스 기록; 배치 추적 구조
- 알아야 할 것: DHR 필수 기록 항목; 배치 추적성; 릴리스 승인 흐름
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

### 포장·멸균배리어 밸리데이션 (ISO 11607) (`packaging-validation`)

- 필요 여부: 해당 시 — 멸균 기기 한정 — 멸균 밸리데이션과 별개.
- 근거 조항: ISO 11607-1, ISO 11607-2
- 앱에서 열기: `/doc/packaging-validation` (기본 템플릿)
- 왜 쓰는가: 멸균 기기는 사용 시점까지 무균이 유지돼야 한다. 멸균배리어(포장)가 유통·노화 후에도 무결함을 입증해 감염 위험을 막는다.
- 작성 전 준비물: 밀봉·무결성·노화 시험; 포장 사양·공정 파라미터; 운송 시뮬레이션
- 알아야 할 것: ISO 11607-1(설계) vs -2(공정); 밀봉 강도·무결성 시험; 노화·운송 시뮬레이션
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

### 취급·보관·포장·배송 관리 (`product-preservation`)

- 필요 여부: 필수
- 근거 조항: ISO 13485 7.5.11
- 앱에서 열기: `/doc/product-preservation` (기본 템플릿)
- 왜 쓰는가: 유통 과정에서 제품이 손상·변질되면 사용 시점 성능을 보장할 수 없다. 보존 조건을 통제해 출하 후에도 품질을 유지한다.
- 작성 전 준비물: 보관·취급 조건; 콜드체인·유효기간 관리; 배송 검증
- 알아야 할 것: 보관·취급 조건 정의; 콜드체인·모니터링; 배송 포장·검증
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 핵심 내용
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인

### 운송(수송) 밸리데이션 (ISTA 3A) (`transport-validation`)

- 필요 여부: 해당 시 — 소형 IVD는 대개 택배 발송이라 ISTA 3A로 검증한다(팔레트·맞춤 사이클은 ASTM D4169). 운송 중 온도 이탈·진동·낙하가 시약·기기 성능에 영향을 줄 때 해당.
- 근거 조항: ISTA 3A
- 앱에서 열기: `/doc/transport-validation` (기본 템플릿)
- 왜 쓰는가: IVD 시약·기기는 운송 중 온도 이탈·진동·충격을 겪는다. 실제 배송 스트레스를 재현해 도착 시점에도 성능·안정성이 유지됨을 입증, 유통 후 오작동과 오진단 위해를 막는다.
- 작성 전 준비물: 운송 시뮬레이션(진동·낙하·온도) 시험 데이터; 콜드체인 온도 모니터링 로그; 포장 사양·안정성 시험 결과
- 알아야 할 것: 최악 조건 운송 경로·계절 온도 프로파일 정의; ISTA 3A 시험 시퀀스(진동·낙하·압력); 콜드체인 온도 모니터링·수용 기준; 운송 후 성능·안정성 재확인 방법
- 섹션 순서:
  1. 1. 목적 · 적용 범위
  2. 2. 운송 경로 · 조건 · 적용 규격
  3. 3. 근거 · 참조
  4. 4. 검토 · 승인
  5. 5. 포장 구성
  6. 6. 시험 순서 · 조건
  7. 7. 판정 기준
  8. 8. 운송 과정 관리
  9. 9. 결과 · 결론
